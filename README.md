# KODAL MAX & KODAL Analytics Tools

A professional statistical analysis and simulation suite for data pattern recognition. Designed for local data-driven analysis with high-speed processing capabilities.

## Overview
KODAL MAX is a private tool suite developed to assist users in performing statistical simulations and data pattern analysis. This application utilizes historical data to provide insights through various logical and mathematical filters.

### Key Features
* **High-Speed Processing:** Localized data analysis with zero-loading time after initial sync.
* **Smart Filtering Engine:** Modular analytical filters including Parity (Odd/Even), Frequency (Hot/Cold), and Distance Gap analysis.
* **Dynamic Visualization:** Professional heatmap indicators for data pattern identification.
* **Independent Operation:** Fully offline-capable after data synchronization.
* **No-Bloat Policy:** Lightweight architecture with minimal permission requirements (Internet only).

## Distribution
This software is distributed as an independent tool. 

### How to Download
You can download the latest version of the application from the **[Releases Page](https://github.com/kodalmax/app/releases)**.

1. Navigate to the **Releases** section.
2. Download the latest `app-release-vxxx.apk` file.
3. Enable "Install from Unknown Sources" on your Android device settings to install.
